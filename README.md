# OmniCart

The aim of the OmniCart project is to develop an e-commerce website that provides users with a simple, secure, and efficient online shopping experience. Our vision is to be the only go-to online shopping websites that offers a wide range of products with attention on making a swift shopping experience for all. 

Our scope includes product listings (categorical), user accounts and profiles, shopping cart to view order history, payment gateway, feedback feature on products and returning them. Our specific target audience is solely based on students between the ages of 16-24, young adults above 18 and fitness/general consumers. The technology we will use to develop the website is Laravel MVC using Visual studio code and MySQL Workbench to handle database management and querying.
